  <action>
Create `scripts/validate-content.ts` — run via `npx tsx scripts/validate-content.ts`.

Import: `compareTwoStrings` from `string-similarity`, `getAllCityServiceParams` from `../data/helpers`, `GeneratedContent` from `./lib/schemas`, `fs` and `path` from Node builtins.

**Step 1: Load all generated content files**
- Use `getAllCityServiceParams()` to get the full list of 165 combinations
- For each, load `content/generated/{city}/{service}.json`
- Track missing files (not yet generated)
- Parse each as `GeneratedContent`

**Step 2: Word count validation**
- For each loaded file, count words across intro + serviceDescription + localContext + whyChooseUs (split on whitespace, filter empty)
- Flag any file with fewer than 200 words as "thin content"

**Step 3: Uniqueness validation (Dice coefficient)**
- Group all loaded content by service slug
- For each service, compare every pair of cities using `compareTwoStrings(fullTextA, fullTextB)` where fullText is the concatenation of intro + serviceDescription + localContext + whyChooseUs
- Flag any pair with similarity > 0.60 (i.e., less than 40% unique content)
- This is the expensive operation: 11 services x C(15,2) = 11 x 105 = 1,155 comparisons. Still fast with string-similarity.

**Step 4: Report**
Print a structured report:
```
=== Content Validation Report ===

Files: 165/165 found

--- Word Count ---
✓ All pages meet 200-word minimum
(or)
⚠ 3 pages below 200-word minimum:
  - burlingame/garden-boxes: 148 words
  - ...

--- Uniqueness (Dice coefficient, threshold: 0.60) ---
✓ All same-service page pairs are sufficiently unique
(or)
⚠ 5 pairs exceed 60% similarity:
  - garden-boxes: burlingame vs san-mateo — 72.3% similar
  - ...

--- Summary ---
PASS: All checks passed
(or)
FAIL: 3 thin pages, 5 duplicate pairs
```

**Exit code:** Exit 0 on pass, exit 1 on fail. This allows CI integration later.

**CLI flags:**
- `--threshold 0.50` — override similarity threshold (default 0.60)
- `--min-words 250` — override minimum word count (default 200)
- `--verbose` — show similarity scores for ALL pairs, not just flagged ones
